Methods we built on土台にした手法

  • Photo matching against orbital images: NASA JPL's Mars Global Localization on Perseverance (principle only; we did not use its software). 軌道からの画像との写真照合：NASA JPLがパーサヴィアランスで使うMars Global Localization（原理のみ。ソフトウェアは使っていません）。
  • Hazard check from a fitted plane (tilt, roughness, step): GESTALT, Goldberg, Maimone and Matthies, 2002. 平面の当てはめによる危険判定（傾き・でこぼこ・段差）：GESTALT、Goldberg, Maimone, Matthies（2002）。
  • Walking speed: Tobler's hiking function, 1993. Effort: Pandolf, Givoni and Goldman, 1977. 歩く速さ：Toblerの式（1993）。運動の強さ：Pandolf, Givoni, Goldman（1977）。
  • Walk-back limit: Apollo 15 to 17 traverse planning. Planning with uncertainty: Prentice and Roy, 2009. ウォークバック限界：アポロ15〜17号の行動計画。不確かさを含めた計画：Prentice, Roy（2009）。
  • Sun position in the 3D view: NASA GISS Mars24 algorithm (Allison and McEwen, 2000). 3D表示の太陽の位置：NASA GISSのMars24アルゴリズム（Allison, McEwen 2000）。

Softwareソフトウェア

  • Three.js (3D), Leaflet (2D map), Vite and TypeScript.
  • Data processing: Python with rasterio, NumPy, SciPy and Pillow. データ処理：Python（rasterio、NumPy、SciPy、Pillow）。
  • The 3D models and the terrain meshes are original, built for this project. 3Dモデルと地形メッシュは、このプロジェクトのために作ったオリジナルです。
  • Written with the help of an AI coding assistant (Claude Code by Anthropic). AIのコーディングアシスタント（AnthropicのClaude Code）の助けを借りて作りました。
